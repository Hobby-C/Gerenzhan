# 玄川 AI 创作者作品集

这是一个使用原生 HTML、CSS 与 JavaScript 制作的静态单页作品集网站。

## 本地查看

直接打开 `dist/index.html`，或在 `dist` 目录启动任意静态文件服务器。

## 内容维护

- 页面结构和作品信息：`dist/index.html`
- 视觉样式与响应式布局：`dist/styles.css`
- 筛选、项目预览和移动端菜单：`dist/script.js`
- 素材：`dist/assets/`

视频项目使用完整时长的 H.264/AAC 网页版本，点击作品卡后可有声播放、拖动进度和全屏观看。`dist/assets/canva/` 包含页面使用的全部生成视觉元素。

联系按钮当前复制微信昵称“玄川”，可在 `dist/index.html` 中搜索 `data-contact` 替换为实际微信号。
